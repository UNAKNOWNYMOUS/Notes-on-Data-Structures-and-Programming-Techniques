# Assignment 5 — Git Basics

## Read first

Yale Chapter 3:

- 3.6 Version control

## Task

Inside this directory, initialize a Git repo and create a simple commit history.

Suggested commands:

```bash
git init
git status
```

Create `notes.md` with:

- one note about shell commands
- one note about `gcc`
- one note about `gdb` or Valgrind

Commit in at least three separate commits:

1. Add shell notes
2. Add compiler notes
3. Add debugging notes

## Check your work

```bash
bash check_git.sh
```

This checks that a `.git` directory exists, `notes.md` exists, and there are at least three commits.
