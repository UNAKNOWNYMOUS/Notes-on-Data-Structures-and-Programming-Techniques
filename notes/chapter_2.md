## 2.5 How to compile and run programs
### 2.5.1 Creating the program
- The `.c` at the end of a file tells the C compiler the contents are C source code.
### 2.5.2 Compiling and running a program
- The prompt is printed by the system telling me it is waiting for a command.
- The `./` is needed to run a program because the shell, by default, looks for programs in certain standard system directories.
### 2.5.3 Some notes on what the program does
- Standard library code is located in `/usr/include/...`
- Every C program has to have a `main`.
- The convention in Unix is that 0 means success.
